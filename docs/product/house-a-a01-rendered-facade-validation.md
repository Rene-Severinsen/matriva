# House A A01 – pudset facade validation

Status: `A01_RENDERED_FACADE_APPROVED_MATERIAL_REFERENCE`

Den pudsede A01-test er en constrained material transformation af den bevarede A01-original. Human decision har godkendt facade-looket; denne kontrol afslutter den planlagte validering af beskyttede elementer. Pixel-identitet er ikke et krav.

| Kontrol | Resultat |
|---|---|
| Footprint og hushjørner | PASS – samme synlige volumen og hjørner |
| Tagform og tagkant | PASS – samme tagflade, tagsten, udhæng og silhouet |
| Vindue | PASS – samme placering, proportion, rammer og refleksion |
| Hoveddør og sideglas | PASS – samme opening, proportioner og tærskel |
| Tagrende og synlig afvanding | PASS – samme placering og forløb |
| Belægning, terrasse/sti og hæk | PASS – samme permanente spatialstruktur |
| Kamera og komposition | PASS – samme 1672 × 941 framing og motivrelation |
| Facademateriale | PASS – lyst varmt-neutralt mat puds; ingen synlige mursten, fuger eller grid |

Mindre variation i farvetone, tekstur, lysdetaljer og vegetationens mikrodetaljer ligger inden for den eksplicit tilladte edit-tolerance. A01-testen er nu den konkrete photorealistic materialereference. A01's endelige exterior visual character kræver fortsat særskilt natural-garden approval.
